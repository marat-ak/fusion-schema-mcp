Causes: no_probe = the folder was never probed (lineage-only folder, or a crawl folder the probe run did not
reach); failed_probe = the probe returned an nQSError / no status; empty_sql_folder = the probe succeeded but
OBIS returned no physical SQL (measure-only folders such as General Ledger - Balances Real Time "Balances");
alias_mismatch = the outer projection of the physical SQL does not have one alias per logical column;
unresolved_lineage = no DB column reached by the workbook, the alias resolution or the crawl;
derived_no_remarks = a physical expression whose referenced columns carry no remark;
ref_without_remark = a DB column is known but neither the dictionary nor the view-remark table describes it.
